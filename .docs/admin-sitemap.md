## Danh sách trang

| # | Trang | Breadcrumb | Chức năng chính |
|---|-------|-----------|-----------------|
| A1 | Dashboard | Admin / Dashboard | Chỉ số doanh thu, đơn hàng, giao dịch lỗi; biểu đồ 7 ngày; mục cần xử lý; giao dịch gần đây |
| A2 | Product Management | Admin / Products | Danh sách sản phẩm, tìm kiếm, lọc, thêm, sửa, trạng thái hiển thị |
| A3 | Inventory | Admin / Inventory | Tồn kho (on hand, reserved, available), cảnh báo sắp hết, điều chỉnh tồn kho, lịch sử xuất nhập |
| A4 | Transaction Management | Admin / Transactions | Danh sách giao dịch, lọc theo trạng thái, nhận diện giao dịch đã trừ tiền nhưng đơn lỗi |
| A5 | Transaction Detail / Change State | Admin / Transactions / TX-20840 | Chi tiết giao dịch, dòng thời gian, đổi trạng thái (Mark as Success, Refund, Hold), lý do, ghi chú, audit log |
| A6 | Grooming / Service Booking | Admin / Grooming | Danh sách lịch hẹn theo trạng thái (Pending, Confirmed, Completed, Cancelled, No-show), xác nhận lịch, gán groomer, quản lý dịch vụ (thời lượng, giá, chi nhánh) |
| A7 | Staff Management | Admin / Staff | Danh sách nhân sự, lọc theo vai trò/chi nhánh/trạng thái, thêm và sửa tài khoản, phân quyền theo vai trò (Admin, Operations, Finance, Groomer, Support) |
